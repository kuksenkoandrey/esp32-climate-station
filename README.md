# 🌤 ESP32 Climate Station
## Домашняя климат-станция на ESP32-C6 с дисплеем

Кастомное устройство на ESP32-C6: показывает время, дату, погоду за окном,
концентрацию CO₂, температуру, влажность и давление в помещении. Показывает
статус замка и света из Home Assistant, а также текущий трек с медиаплеера.
Управляется одной физической кнопкой и сенсорной кнопкой, интегрируется с Home Assistant.

## 📸 Что умеет

- 🕐 **Часы** — большие цифры, дата, день недели
- 🌡 **Климат в помещении** — CO₂ (HC8), температура и влажность (AHT20), давление (BMP280)
- 🌤 **Погода за окном** — температура с улицы (из Home Assistant)
- 🔒 **Статус замка** — открыт/закрыт (из Home Assistant)
- 💡 **Статус света** — включён/выключен (из Home Assistant)
- 🎵 **Медиаплеер** — текущий трек (название и исполнитель, бегущая строка)
- ⏰ **Будильник** — время ближайшего события из календаря Home Assistant
- 🎛 **3 режима экрана** — Часы / Инфо / Выкл
- ⚙️ **Меню настроек** — 3 уровня яркости подсветки (4% / 30% / 100%)
- 💡 **RGB-светодиод** — 3 режима: красный, тёплый белый, LSD-эффект
- 🔘 **Управление одной кнопкой** — 1 клик, 2 клика, долгое нажатие (3с, 5с)

## 🔌 Железо

Список компонентов, которые использовались в сборке (без брендов — просто типы):

| Что | Характеристики | Зачем |
|-----|----------------|-------|
| **ESP32-C6** | Вариант N4/N8/N16, WiFi 6, Bluetooth, Zigbee | Основной микроконтроллер |
| **TFT-дисплей** | 2.0", модель ST7789V, 240×320, SPI | Экран, на котором всё отображается |
| **Датчик CO₂** | HC8, UART | Измерение концентрации CO₂ |
| **Датчик t°/влажности** | AHT20, I2C | Температура и влажность в помещении |
| **Датчик давления** | BMP280, I2C, адрес 0x77 | Атмосферное давление |
| **Полевой MOSFET** | AO3401 (P-канальный, SOT-23, 4.1A, 30V) | Управление подсветкой экрана через ШИМ |
| **Сенсорная кнопка** | TTP223 (2.5–5.5В) | Сенсорная кнопка (GPIO15) |
| **Тактовая кнопка** | Обычная, выпаяна со старой платы | Физическая кнопка (GPIO9) |
| **Лист ABS-пластика** | 250×300×3 мм, чёрный, тиснёный, 2 шт | Корпус устройства |
| **Пруток ABS для 3D-ручки** | 70 м, белый | «Паутина» для вентиляции в корпусе |

**Корпус** собран из листового ABS-пластика, склеен суперклеем.
Часть корпуса выполнена 3D-ручкой в виде «паутины» — чтобы воздух проходил к датчикам.

## 📍 Распиновка

| Компонент | Пин ESP32 |
|-----------|-----------|
| Дисплей ST7789V | SPI: CLK=GPIO6, MOSI=GPIO7, CS=GPIO18, DC=GPIO19, RST=GPIO20 |
| I2C (AHT20 + BMP280) | SDA=GPIO2, SCL=GPIO3 |
| UART (HC8 CO₂) | TX=GPIO5 (в RX датчика), RX=GPIO4 (в TX датчика) |
| Физическая кнопка | GPIO9 (INPUT_PULLUP, inverted) |
| Сенсорная кнопка | GPIO15 (INPUT_PULLUP, inverted) |
| Подсветка дисплея | GPIO10 (LEDC ШИМ) |
| RGB-светодиод | GPIO8 (WS2812) |

## 🚀 Установка

1. Установи **ESPHome** (в Home Assistant или отдельно).
2. Скопируй папки `esphome/` и `components/` в свой конфиг ESPHome.
3. Скопируй `esphome/secrets.example.yaml` → `esphome/secrets.yaml` и заполни:
   - `wifi_ssid`, `wifi_password` — данные твоего Wi-Fi
   - `fallback_password` — пароль резервной точки доступа (свой!)
   - `api_key` — сгенерируется в ESPHome автоматически
4. Открой `esphome/climate-station.yaml` и проверь под свои датчики:
   - `entity_id` — для замка, света, медиаплеера, календаря, погоды
   - Пины — если у тебя другая плата
5. Прошей ESP32 через ESPHome.

## 🎛 Управление кнопкой

Устройством можно управлять **одной физической кнопкой** (GPIO9):

| Действие | Что происходит |
|----------|----------------|
| **1 клик** | Переключить экран: Часы → Инфо → Выкл → Часы |
| **2 клика** | Открыть меню настроек подсветки |
| **Долгое 3 сек** | Включить/выключить RGB-светодиод |
| **Долгое 5 сек** | Открыть меню выбора режима светодиода |

**В меню настроек:**
- 1 клик — выбрать следующий пресет яркости (4% / 30% / 100%)
- 2 клика — выйти из меню

**В меню светодиода:**
- 1 клик — выбрать следующий режим (Красный / Тёплый белый / LSD)
- 2 клика — выйти из меню

## 💡 Что проверено

- ✅ CO₂ (HC8) — работает, но требует прогрева 1–3 минуты
- ✅ Температура и влажность (AHT20) — работают, с калибровочным offset
- ✅ Давление (BMP280) — работает, пересчёт в мм рт. ст.
- ✅ Дисплей ST7789V — работает
- ✅ Управление кнопкой — работает
- ✅ RGB-светодиод — работает
- ✅ Интеграция с Home Assistant — работает

## ⚠️ Грабли

1. **HC8 нужно время на прогрев.** Первые 1–3 минуты показания CO₂ могут быть неверными.
2. **AHT20 требует калибровки.** В моём случае offset: температура −2.33°C, влажность +9.67%.
3. **BMP280 надо пересчитать.** Датчик отдаёт давление в гПа, для мм рт. ст. умножаем на 0.75006.
4. **Fallback Hotspot** — если Wi-Fi отвалится, ESP32 поднимет свою точку доступа.
   Пароль **обязательно** смени на свой в `secrets.yaml`.
5. **Дисплей ST7789V** — при первом запуске может понадобиться поменять `invert_colors: true/false`.
6. **AO3401 (P-канальный MOSFET)** — управление подсветкой идёт через него, GPIO10 идёт на затвор.
   Если подсветка не работает — проверь, правильно ли впаян транзистор.

## 🏠 Интеграция с Home Assistant

Устройство подтягивает данные из Home Assistant через `homeassistant`-платформу:
- `switch.example_lock` — статус замка
- `light.example_light` — статус света
- `media_player.example_player` — текущий трек
- `calendar.example_calendar` — ближайшее событие
- `weather.example_weather` — температура за окном

**Замени эти `entity_id` на свои** в `esphome/climate-station.yaml`.
